🚀 INÍCIO RÁPIDO - 5 MINUTOS
═══════════════════════════════════════════════════════════════════════════════

1. EMAIL (Gmail com 2FA):
   ┌─────────────────────────────────────────────────────────────────┐
   │ 1. Ativa 2FA no Google (security.google.com)                   │
   │ 2. Gera "App Password" (16 caracteres)                          │
   │ 3. cURL:                                                        │
   │                                                                 │
   │ curl -X PUT "http://localhost:8000/notifications/config" \    │
   │   -H "Authorization: Bearer TOKEN" \                           │
   │   -H "Content-Type: application/json" \                        │
   │   -d '{                                                         │
   │     "email_provider": "gmail",                                  │
   │     "smtp_username": "seu@gmail.com",                           │
   │     "smtp_password": "xxxx xxxx xxxx xxxx",                    │
   │     "smtp_enabled": true,                                       │
   │     "trigger_critical": true,                                   │
   │     "trigger_high": true                                        │
   │   }'                                                            │
   │                                                                 │
   │ 4. Testar: POST /notifications/test/email                      │
   └─────────────────────────────────────────────────────────────────┘

2. TELEGRAM:
   ┌─────────────────────────────────────────────────────────────────┐
   │ 1. Chat @BotFather → /newbot (cria bot)                        │
   │ 2. Copia token recebido: 123456:ABC...                          │
   │ 3. Envia mensagem ao bot                                        │
   │ 4. GET https://api.telegram.org/bot{TOKEN}/getUpdates          │
   │ 5. Copia chat_id                                                │
   │ 6. PUT /notifications/config com token + chat_id               │
   │ 7. Testar: POST /notifications/test/telegram                   │
   └─────────────────────────────────────────────────────────────────┘

3. GERAR PDF:
   ┌─────────────────────────────────────────────────────────────────┐
   │ curl -X GET "http://localhost:8000/reports/export/pdf\         │
   │   ?period=24h&severity=all&tipo=detalhado&limite=500" \        │
   │   -H "Authorization: Bearer TOKEN" \                           │
   │   -o aegis-report.pdf                                           │
   │                                                                 │
   │ → Arquivo salvo: aegis-report.pdf                              │
   └─────────────────────────────────────────────────────────────────┘
